# urotriage-project

Тут два проекта:

- `botkin-urotriage` — правило + ML-модель + REST API (порт 8000)
- `urotriage-webapp` — веб-приложение для врача (порт 8080), ходит в API светофора

Модель уже обучена и лежит в `botkin-urotriage/models/model_v4.joblib`, ничего обучать не надо.

## Запуск

Нужен Python 3.10+.

```bash
./install.sh   # один раз, создаст .venv и поставит зависимости
./start.sh
```

Открыть http://localhost:8080 — это приложение. Сваггер API на http://localhost:8000/docs.

С телефона: узнать IP компа и открыть `http://<ip>:8080`, телефон должен быть в той же вайфай-сети.

## Данные

Всё складывается в `urotriage-webapp/data/`, папка создаётся при первом запуске:

- `records.db` — sqlite со всеми записями, бэкапить достаточно этот файл
- `анкета_актуальная.xlsx` — выгрузка в формате анкеты, обновляется сама после каждого сохранения

## Деплой на сервер

Код не меняется. Копируете папку, install.sh + start.sh, сверху nginx с https на порт 8080. Пример конфига есть в `urotriage-webapp/README.md`. https обязателен, иначе PWA не установится на телефон (на localhost работает и так).

## Грабли

- sklearn зафиксирован на 1.8.0, модель обучена на нём. Поменяете версию — переобучайте (`python scripts/run_training.py` в botkin-urotriage), иначе полезут InconsistentVersionWarning.
- Если API светофора лежит, приложение всё равно работает и сохраняет записи, просто без зоны. Зона пересчитается при редактировании записи.
- Подробности по каждому проекту — в их README, по решениям в приложении — `urotriage-webapp/docs/decisions.md`.
